# Roblox-Cool-Camera

Hello again! This script will make your local camera in Roblox way more realistic!
Well, let's get started. Ill help you to insert it in your game right.

First you need to do is to create a LocalScript in StarterPlayer\StarterCharacterScripts
And secondly you will need to create a new ScreenGui in StarterGui folder. Name it with "Cursor" or whatever you need, but know that youll have to rename the variable at Line 10 in CameraScript.lua .
Then you need to create an ImageLabel in this ScreenGui, insert any rbxassetid in Image property of ImageLabel.

Thats all! Thanks for using.
